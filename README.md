# Servipro Limpieza 507

Sitio web comercial para Servipro Limpieza 507, enfocado en limpieza industrial, silos, graneleros, bodegas, espacios confinados y operaciones logísticas en Panamá.

## Comandos

```bash
npm install
npm run dev
npm run build
```

## Contacto

Los botones de WhatsApp apuntan a `+507 6995-0464` con mensaje de cotización precargado.

## GitHub y Hostinger

1. Crea un repositorio en GitHub y sube este proyecto.
2. En Hostinger, conecta el repositorio desde su integración de Git.
3. Usa `npm install` como instalación y `npm run build` como comando de build.
4. Si el plan de Hostinger es solo estático, genera una variante estática antes de publicar.
